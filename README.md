# 小毛豆 QQ Companion

小毛豆是一个自研 QQ 官方机器人，用于两个人的私人群聊：

- 全量群消息实时入库，作为上下文
- 只有被 @ 时才回复
- 使用 DeepSeek 的 `deepseek-chat`
- 本地 SQLite 保存聊天记录
- 支持自然语言定时任务
- 支持长期记忆、会话摘要和历史消息检索

## Run

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

Or run it as a hidden background service on Windows:

```powershell
.\scripts\start.ps1
.\scripts\status.ps1
.\scripts\stop.ps1
```

QQ 开放平台中选择 WebSocket 连接方式。机器人资料页开启“接收所有消息”后，普通群聊会通过 `GROUP_MESSAGE_CREATE` 推送。

## Try

在群里 @ 小毛豆：

```text
@小毛豆 总结一下我们刚才聊了什么
@小毛豆 给我们开一个轻松的新话题
@小毛豆 帮我把这句话说得温柔一点：...
```

小毛豆不是固定命令机器人；以上只是示例，直接用自然语言提出需求即可。

## Scheduled Tasks

通过 @ 小毛豆直接设置和管理任务：

```text
@小毛豆 每天 22:00 提醒我们互道晚安
@小毛豆 每周五 19:00 发一个周末约会建议
@小毛豆 明天 09:00 提醒我问她周末安排
@小毛豆 10 月 24 日 09:00 发纪念日祝福
@小毛豆 2027 年 2 月 6 日早上 09:00 发一条新年祝福
@小毛豆 查看任务
@小毛豆 取消晚安提醒
@小毛豆 暂停任务 2
@小毛豆 恢复任务 2
@小毛豆 跳过下一次晚安提醒
```

当前支持单次、每天和每周任务。主动消息默认在 `23:30` 到 `07:00` 不发送；主动消息是否可发还受 QQ 开放平台权限和额度限制。
具体日期由你在 @ 消息中直接给出，小毛豆不内置节假日日历，也不会自行猜测节日对应的日期。

## Memory

```text
@小毛豆 记住她不吃香菜
@小毛豆 查看记忆
@小毛豆 忘记她不吃香菜
@小毛豆 我们之前聊过哪家餐厅？
@小毛豆 她之前说过不喜欢什么礼物？
```

聊天达到一批后，后台会自动生成会话摘要，并提取适合长期保存的偏好、约定、纪念日和关系事件。密码、身份证号、银行卡号、验证码、住址门牌等敏感信息不会被主动保存到长期记忆。

## Privacy

- 聊天原文保存在本机 `data/xiaoxia.sqlite3`
- @ 触发时，最近聊天会发送给 DeepSeek 的指定模型
- `AppSecret` 和 API Key 保存在 `.env`，请勿提交或发到聊天里
