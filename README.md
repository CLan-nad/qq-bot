# 小毛豆

一个适合情侣私人群聊的 QQ 机器人。平时安静待在群里，被 @ 时才会参与聊天。

## 可以做什么

- 陪你聊天、开启新话题
- 总结最近的聊天内容
- 看懂群里发的图片，包括聊天截图、照片和表情包
- 联网搜索资料、打开并总结网页
- 读取并解析 PDF、Word、Excel 和文本文件
- 计算数学表达式，或在受限沙箱里执行本地命令
- 帮忙润色想说的话
- 按日期或周期发送提醒和祝福
- 记住两个人的偏好、约定和重要日子

通过自然语言直接 @ 小毛豆即可，不需要记固定命令：

```text
@小毛豆 总结一下我们刚才聊了什么
@小毛豆 给我们开一个轻松的新话题
@小毛豆 明天 09:00 提醒我们周末约会
@小毛豆 记住她不吃香菜
@小毛豆 查看记忆
@小毛豆 搜一下周末上海有哪些展览
@小毛豆 帮我总结这份文档
@小毛豆 算一下 (1+0.03)^30
```

## 运行

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

也可以使用 Windows 后台脚本：

```powershell
.\scripts\start.ps1
.\scripts\status.ps1
.\scripts\stop.ps1
```

QQ 开放平台选择 WebSocket 连接，并开启接收群消息。

## 隐私

聊天记录、图片描述和长期记忆保存在部署机器本地。机器人需要生成回复时，只会把完成任务所需的上下文发送给你配置的大模型服务；图片本身不下载、不落盘，只交给模型识别内容。`.env` 中的密钥请勿提交到 Git。
